# Portal TechGames 🎮

Projeto desenvolvido em **Angular** para a exibição e gestão do catálogo do portal **TechGames**. O projeto conta com uma interface moderna, responsiva e estruturada em componentes reaproveitáveis.

## 🚀 Tecnologias Utilizadas

- **Angular** (HTML, CSS e TypeScript)
- **Git & GitHub** (Versionamento de código)

---

## 📁 Estrutura do Projeto

A aplicação está organizada nos seguintes componentes principais:

- **Cabeçalho (`cabecalho`)**: Navegação principal e marca do portal.
- **Detalhes do Jogo (`detalhes-jogo`)**: Card dinâmico com informações, imagem, gênero, preço e botão de compra.
- **Rodapé (`rodape`)**: Links de redes sociais e direitos autorais.
- **Estilos Globais (`app.css` / `styles.css`)**: Definição de layout base e reset CSS.
